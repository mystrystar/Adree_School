# Adree School Student Dashboard

A polished React 19 + TypeScript student dashboard built with Vite, Tailwind CSS, React Router, TanStack Query, React Hook Form, Zod, Framer Motion, and Lucide icons.

## Highlights

- Login screen with Zod validation and responsive design
- Student catalog fetched from JSONPlaceholder with loading, error, empty, and success states
- Debounced search, company multi-select filters, and A-Z / Z-A sorting
- Right-side student details drawer with avatar, company, and address information
- Dark mode and local persistence for theme/auth preferences
- Lazy-loaded routes and a React Error Boundary for graceful failures

## Run locally

```bash
npm install
npm run dev
```

## Build and test

```bash
npm run build
npm test -- --run
```
